# jgabor.se

My personal site. Built with Astro 6, Tailwind CSS 4, and Vite+ (Rolldown). Runs on Cloudflare Workers.

## Development

```sh
vp install
vp dev
```

## Scripts

| Command         | Description                    |
| --------------- | ------------------------------ |
| `vp dev`        | Start local dev server         |
| `vp build`      | Build for production           |
| `vp preview`    | Preview production build       |
| `vp deploy`     | Build and deploy to Cloudflare |
| `vp type-check` | Run `astro check`              |
| `vp lint`       | Lint `src/`                    |
| `vp fmt`        | Format `src/`                  |
| `vp check`      | Run all checks                 |
